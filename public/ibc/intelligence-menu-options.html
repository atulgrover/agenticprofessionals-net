Redesigning the "Actions" Section (Chats • Drafts • Tasks)

Currently, the Intelligence menu mirrors the exact same 3-row list on both sides: Assets (brains / knowledge / skills) on the left, and Actions (chats / drafts / tasks) on the right. Because Assets are static intellectual capital, while Actions are interactive tools and execution workflows, representing them differently creates immediate visual contrast and functional clarity.

Option 1 • Recommended • Sovereign Workspace Dock

Passive Intelligence (Left) vs Active Execution Cockpit (Right)

The right side is transformed into a sleek, unified tool cockpit. Each action (Chats, Drafts, Tasks) gets an interactive trigger tile, with a unified bottom portal gateway.
